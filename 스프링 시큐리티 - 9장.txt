스프링 시큐리티 - 9장

접근 권한을 설정하는 시큐리티 태그

<http> 태그
• 스프링 시큐리티 설정의 핵심
• 시작과 끝 태그(<http>...</http>) 안에 스프링 시큐리티와 관련된 내용을 포함하는 최상위 태그

2가지 속성 
1. auto-config : 일반적인 웹 애플리케이션에 필요한 기본 보안 서비스를 자동 설정
2. use-expressions : <intercept-url> 태그의 access 속성에서 스프링 표현 언어(SpEL)를 사용할 수 있는지 여부


<intercept-url> 태그
• 접근 권한에 대한 URL 패턴을 설정
• <http> 태그 안에 여러 개 설정할 수 있고 선언된 순서대로 접근 권한이 적용됨

3가지 속성
pattern ant 경로 패턴(?:문자 한 개와 매칭, *: 0개 이상의 문자와 매칭, **:0개이상의 디렉터리와 매칭)을 사용하여 접근 경로를 설정
2. access : pattern에 설정된 경로 패턴에 접근할 수 있는 사용자 권한을 설정
3. requires-channel : 정의된 패턴 URL로 접근하면 설정된 옵션 URL로 리다이렉션하도록 설정
※ 옵션으로 http, https, any 가 있음
